# Round 9 directional remainder jets

This note derives the bounds implemented by `experiments/directional_norm_jets.py`. It is a bounded, one-case method note for the frozen Round 9 path. It does not extend the L01 theorem or make a novelty claim.

## Real-arithmetic setting

Fix the decoder parameters, one P reference cache, one positive mass-preserving summary cache, one discrete token history, and its absolute token positions. Let \(\theta\in[0,1]\) interpolate only the old-prefix attention measure:
\[
w_i(\theta)=
\begin{cases}
(1-\theta)w_i^P,&i\in P,\\
\theta w_i^Q,&i\in Q,\\
1,&i\text{ is an already generated suffix atom}.
\end{cases}
\]
The fixed prefix and summary keys and values do not depend on \(\theta\). Each suffix key and value is generated by the same \(\theta\)-dependent decoder and is carried forward with its own path derivatives. The P and summary prefix masses agree, \(\sum_iw_i^P=\sum_iw_i^Q=n\); all masses are nonnegative. Every attention denominator is therefore positive.

For a vector-valued path \(x\), a jet is the triple
\[
(x_0,x_1,B_x),\qquad x_0=x(0),\quad x_1=x'(0),\quad
B_x\ge\sup_{\theta\in[0,1]}\|x''(\theta)\|_2.
\]
Taylor's integral formula gives, for every \(\theta\in[0,1]\),
\[
\|x(\theta)-x_0-\theta x_1\|_2\le \tfrac12B_x\theta^2,
\qquad
\|x'(\theta)\|_2\le\|x_1\|_2+B_x.
\]
All bounds below are real-arithmetic inequalities. The current implementation evaluates their ingredients in float64 with ordinary Torch operations; it does not use outward-rounded intervals, so its numerical outputs are not formal certificates.

## Linear maps and residuals

For \(y=Wx+b\),
\[
y_0=Wx_0+b,\qquad y_1=Wx_1,\qquad
B_y\le\|W\|_2B_x.
\]
Biases have zero derivatives. For a residual sum \(y=x+u\), add the values and signed tangents and use \(B_y\le B_x+B_u\). Thus the implementation preserves the direction of the first derivative through the full suffix graph and bounds only the second-order uncertainty.

## LayerNorm

Let \(P_d=I-\mathbf1\mathbf1^\top/d\), \(c(\theta)=P_dx(\theta)\), and
\[
s(c)=\sqrt{\|c\|_2^2/d+\varepsilon},\qquad
\operatorname{LN}(x)=\gamma\odot c/s(c)+\beta,\quad \varepsilon>0.
\]
Write \(c_0=P_dx_0\), \(c_1=P_dx_1\), and \(B=B_x\). Then
\[
c(\theta)=c_0+\theta c_1+r(\theta),\quad \|r(\theta)\|\le B/2,
\qquad \|c'(\theta)\|\le G:=\|c_1\|+B.
\]
The code computes the distance of the affine segment to zero by projecting \(c_0\) onto \(c_1\):
\[
C_{\rm seg}^{\min}=\min_{0\le t\le1}\|c_0+tc_1\|,\quad
C_{\rm seg}^{\max}=\max(\|c_0\|,\|c_0+c_1\|).
\]
Consequently
\[
C_{\min}=\max(0,C_{\rm seg}^{\min}-B/2),\quad
C_{\max}=C_{\rm seg}^{\max}+B/2,\quad
s_{\min}=\sqrt{C_{\min}^2/d+\varepsilon}.
\]
In particular, the normalization denominator never approaches zero because \(\varepsilon>0\).

For \(\phi(c)=c/s(c)\), direct differentiation gives
\[
D\phi(c)[u]=u/s-(c^\top u)c/(d s^3),
\]
\[
D^2\phi(c)[u,v]=-\frac{(c^\top u)v+(c^\top v)u+(u^\top v)c}{d s^3}
+\frac{3(c^\top u)(c^\top v)c}{d^2s^5}.
\]
The Jacobian norm is at most \(1/s\). Since \(s^2=\varepsilon+\|c\|^2/d\), the Hessian norm is at most \(6/(\sqrt d\,s^2)\): the first three terms together are at most \(3/(\sqrt d\,s^2)\), and the last is at most the same amount. With \(\gamma_{\max}=\|\gamma\|_\infty\), this yields
\[
B_{\rm LN}\le \gamma_{\max}B/s_{\min}
+\frac{6\gamma_{\max}G^2}{\sqrt d\,s_{\min}^2}.
\]

The implementation also computes a direction-sensitive Hessian bound. Put \(V_{\rm dot}\ge\sup_\theta|c(\theta)^\top c'(\theta)|\), with
\[
V_{\rm dot}=
\max\{|c_0^\top c_1|,\ |c_0^\top c_1+\|c_1\|^2|\}
+C_{\rm seg}^{\max}B+\tfrac12B\|c_1\|+\tfrac12B^2.
\]
This follows by expanding \(c=c_0+\theta c_1+r\) and \(c'=c_1+r'\), where \(\|r\|\le B/2\) and \(\|r'\|\le B\). Substituting \(u=v=c'\) into the Hessian formula gives
\[
H_{\rm dir}=\gamma_{\max}\left[
\frac{2G V_{\rm dot}}{d s_{\min}^3}
+\frac{C_{\max}G^2}{d s_{\min}^3}
+\frac{3C_{\max}V_{\rm dot}^2}{d^2s_{\min}^5}
\right].
\]
The chain rule separates \(D\phi[c'']\), bounded by \(B/s_{\min}\), from \(D^2\phi[c',c']\). The implemented bound is therefore
\[
B_{\rm LN}\le \gamma_{\max}B/s_{\min}
+\min\!\left\{\frac{6\gamma_{\max}G^2}{\sqrt d\,s_{\min}^2},H_{\rm dir}\right\}.
\]

## Exact GELU

For \(g(x)=x\Phi(x)\), with standard normal density \(\varphi\),
\[
g'(x)=\Phi(x)+x\varphi(x),\qquad
g''(x)=(2-x^2)\varphi(x).
\]
Because \(0\le\Phi\le1\) and \(\sup_x|x|\varphi(x)=1/\sqrt{2\pi e}<1/4\), \(|g'|\le1.25\). For \(|x|\le\sqrt2\), \(|g''|\le2/\sqrt{2\pi}<0.8\). For \(|x|\ge\sqrt2\), writing \(t=x^2\ge2\) gives \(|g''|=(t-2)e^{-t/2}/\sqrt{2\pi}\), whose maximum occurs at \(t=4\) and is less than \(0.8\). Thus \(|g''|\le0.8\) globally.

For a vector input jet \((x_0,x_1,B_x)\), set \(L=1.25\), \(H=0.8\). Since \(x'=x_1+\delta\) with \(\|\delta\|_2\le B_x\),
\[
\|(x')^{\odot2}\|_2
\le\|x_1^{\odot2}\|_2+2\|x_1\|_\infty B_x+B_x^2.
\]
Applying the scalar chain rule coordinatewise gives the implemented bound
\[
B_{g(x)}\le L B_x+
H\big(\|x_1^{\odot2}\|_2+2\|x_1\|_\infty B_x+B_x^2\big).
\]

## Weighted attention

At one query, concatenate fixed P atoms, fixed summary atoms, and all suffix atoms generated so far. The implementation chooses one fixed key center \(c\) from the \(\theta=0\) keys and defines
\[
s_i(\theta)=q(\theta)^\top(k_i(\theta)-c)/\sqrt d.
\]
Subtracting the same \(q(\theta)^\top c\) from every score leaves normalized attention unchanged. The center is held fixed during differentiation. For key and query jets \((k_0,k_1,B_k)\), \((q_0,q_1,B_q)\), define \(k_0^c=k_0-c\). The product rule and the jet bounds give
\[
B_{s_i}\le \frac{
B_q(\|k_{i0}^c\|+\|k_{i1}\|+B_{k_i}/2)
+B_{k_i}(\|q_0\|+\|q_1\|+B_q/2)
+2\big(|q_1^\top k_{i1}|+\|q_1\|B_{k_i}
+\|k_{i1}\|B_q+B_qB_{k_i}\big)}
{\sqrt d}.
\]
The signed product \(q_1^\top k_{i1}\) is kept before bounding the tangent variation. In particular, this includes all cross terms in \(q'^\top k'\). Let \(s_{i0},s_{i1}\) be the value and signed tangent at zero and set
\[
\rho_i=|s_{i1}|+B_{s_i}/2.
\]
Then \(|s_i(\theta)-s_{i0}|\le\rho_i\).

The atom masses are affine: \(w_i(\theta)=w_{i0}+\theta w_{i1}\). They are \((w^P,-w^P)\) for P atoms, \((0,w^Q)\) for summary atoms, and \((1,0)\) for suffix atoms. At \(\theta=0\), choose the fixed scalar shift \(s_{\max}=\max_i s_{i0}\) and normalize exponentials by the exact same-history P denominator:
\[
e_{i0}=
\frac{\exp(s_{i0}-s_{\max})}
{\sum_j w_{j0}\exp(s_{j0}-s_{\max})},\qquad
g_{i0}=w_{i0}e_{i0}.
\]
Thus \(D(0)=\sum_i g_{i0}=1\). This normalization is constant in \(\theta\), not the moving attention denominator. It avoids logarithms of masses: summary atoms with \(w_{i0}=0\) have finite derivatives.

The score enclosure gives
\[
e_i^+=e_{i0}e^{\rho_i},\quad e_i^-=e_{i0}e^{-\rho_i},\quad
B_{e_i}=e_i^+\big(B_{s_i}+(|s_{i1}|+B_{s_i})^2\big).
\]
Indeed \(e_i'=e_i s_i'\), \(e_i''=e_i((s_i')^2+s_i'')\), and
\(\sup|s_i'|\le |s_{i1}|+B_{s_i}\). A valid derivative bound, tightened by taking the smaller of two valid bounds, is
\[
G_{e_i}=\min\{e_i^+(|s_{i1}|+B_{s_i}),\ |e_{i0}s_{i1}|+B_{e_i}\}.
\]

For \(g_i(\theta)=w_i(\theta)e_i(\theta)\), let
\[
w_i^+=\max(w_{i0},w_{i0}+w_{i1}),\quad
B_{g_i}=w_i^+B_{e_i}+2|w_{i1}|G_{e_i},\quad
G_{g_i}=\min\{|w_{i1}|e_i^++w_i^+G_{e_i},\ |g_{i1}|+B_{g_i}\},
\]
where \(g_{i1}=w_{i1}e_{i0}+g_{i0}s_{i1}\), \(g_i^+=w_i^+e_i^+\), and \(G_{g_i}\ge\sup|g_i'|\). These follow from the product rule and from the Taylor bound on \(g_i'\).

Let \(v_i\) have jet \((v_{i0},v_{i1},B_{v_i})\). Define
\[
D=\sum_i g_i,\qquad N=\sum_i g_iv_i,\qquad
a_0=N(0),\qquad U=N-a_0D.
\]
Because \(D(0)=1\), \(a_0=A(0)\) for \(A=N/D\); hence \(U(0)=0\) exactly and \(A'(0)=U'(0)=:U_1\), where
\[
U_1=\sum_i\left[g_{i1}(v_{i0}-a_0)+g_{i0}v_{i1}\right].
\]
The implementation uses
\[
\begin{aligned}
V_i^+&=\|v_{i0}-a_0\|+\|v_{i1}\|+B_{v_i}/2,&
G_{v_i}&=\|v_{i1}\|+B_{v_i},\\
B_U&=\sum_i(B_{g_i}V_i^++2G_{g_i}G_{v_i}+g_i^+B_{v_i}),&
B_D&=\sum_iB_{g_i},\qquad D_1=\sum_i g_{i1}.
\end{aligned}
\]
These bound \(\sup\|U''\|\) and \(\sup|D''|\) by differentiating \(g_i(v_i-a_0)\) and \(g_i\).

For a positive denominator lower bound, write
\[
\ell_P=\sum_{i\in P}w_{i0}e_i^-,\quad
\ell_Q=\sum_{i\in Q}w_{i1}e_i^-,\quad
\ell_S=\sum_{i\in S}w_{i0}e_i^-.
\]
Then
\[
D(\theta)\ge(1-\theta)\ell_P+\theta\ell_Q+\ell_S
\ge D_{\min}:=\min(\ell_P,\ell_Q)+\ell_S>0.
\]
The first inequality uses nonnegative masses and each atom's lower exponential bound; the second uses the affine interpolation of the two equal-mass prefix measures. Since \(U(0)=0\), set
\[
U_{\max}=\|U_1\|+B_U/2,\quad
G_U=\|U_1\|+B_U,\quad
G_D=|D_1|+B_D.
\]
For \(A=a_0+U/D\), differentiating twice yields
\[
A''=\frac{U''}{D}-\frac{2U'D'}{D^2}
-\frac{UD''}{D^2}+\frac{2U(D')^2}{D^3}.
\]
Therefore
\[
B_A\le
\frac{B_U}{D_{\min}}
+\frac{2G_UG_D}{D_{\min}^2}
+\frac{U_{\max}B_D}{D_{\min}^2}
+\frac{2U_{\max}G_D^2}{D_{\min}^3}.
\]
This attention jet is then passed through the output projection and residual/MLP path. The appended suffix K/V use the resulting signed tangent and second-derivative bounds in every later query.

## Logits, conditional KL, and sequence aggregation

Center the output head as \(W_c=(I-\mathbf1\mathbf1^\top/V)W\), where \(V\) is vocabulary size. Its jet is
\[
z_0=W_cx_0,\quad z_1=W_cx_1,\quad B_z\le\|W_c\|_2B_x.
\]
The endpoint difference is centered already, and
\[
\|z(1)-z(0)\|_2\le \|z_1\|_2+B_z/2.
\]
For \(p=\operatorname{softmax}(z(0))\), \(q=\operatorname{softmax}(z(1))\), the log-partition Hessian is \(\operatorname{diag}(p)-pp^\top\), whose operator norm is at most \(1/2\). The KL is its Bregman remainder, so
\[
D_{\rm KL}(q\|p)\le \tfrac14\|z(1)-z(0)\|_2^2.
\]
Intersect this conditional bound with any separately valid P-only Round 9 conditional bound and the reference cap \(-\log\min_a p(a)\).

For each history \(h\), let \(b(h)\) be a P-only upper bound on its conditional \(D_{\rm KL}(Q(\cdot|h)\|P(\cdot|h))\). For a complete token sequence \(y\), define the path envelope
\[
R(y)=\sum_{t=0}^{T-1}b(y_{<t}),\qquad
P(y)=\prod_{t=0}^{T-1}P(y_t\mid y_{<t}).
\]
The KL chain rule gives \(D(Q\|P)\le\mathbb E_Q R\le\max_yR(y)\). For every \(\lambda>1\), the entropy variational inequality also gives
\[
(\lambda-1)D(Q\|P)\le \log\mathbb E_P e^{\lambda R(Y)}.
\]
Thus any finite-tree maximum-path bound, or any selected \(\lambda>1\) evaluated using the P leaf probabilities, is a safe P-only sequence upper bound; take the minimum of valid candidates. Do not replace the Q expectation by a P average of \(b(h)\). The computation covers one frozen model, prefix, summary, horizon, and history tree; it does not establish a multi-model or long-horizon result.

# Round 9: frozen slack and directional derivative diagnostic

This is a mechanism diagnostic after the failed half-cache feasibility gate,
not another certification experiment. It reuses one original qualified Round 6
checkpoint without training. Its results cannot establish a uniform theorem,
a multi-model effect, long-horizon fidelity, or publication novelty.

## Frozen question and selection

Which source of sufficient-bound slack dominates in one preselected case:
hidden-state propagation, final LayerNorm, output orientation, or softmax
curvature? Does a full-network directional derivative approximate the finite
compression response in that case?

Before computing new outputs, choose the first model seed in the frozen Round 9
list (11) and the first n=64 prefix (`histogram-n64-0000`). Use positive
agglomerative means with m=32, T=4, and the full three-token vocabulary. Cover
all 40 prediction histories and 81 sequence leaves. The existing Round 9
checkpoint, prefix and source hashes are checked. No alternate prefix is chosen
if this case is unrepresentative or the derivative is poor.

## Intervention and controls

At each layer the old-prefix measure is
`M(theta)=(1-theta)*M_full+theta*M_summary`, on the union of n+m fixed atoms.
Summary atoms carry their original positive cluster-size weights; prefix mass
is n at every theta. Subsequent suffix KVs are generated by that same theta
decoder, remain differentiable, and have weight one. All decoders receive the
same discrete token history. Token positions are n,n+1,..., independent of
cache atom count. Attention uses shifted exponentials and explicit weights;
it never differentiates log zero weights.

The theta=0 and theta=1 logits and hidden states must agree with the existing
P and Q implementations for every history. Identity compression is a software
control. The forward-mode JVP at zero is checked against a second-order
one-sided finite difference with frozen h=1e-4. Software checks must pass
before interpreting the scientific output. These are float64 checks, not
outward-rounded interval certification.

## Measurements

For every history, retain raw vectors and norms, exact P/Q masses and
conditional KL, the Round 9 hidden radii, and actual layer/token hidden
displacements. At the final prediction state separately compare:

1. Round 9 hidden radius versus actual hidden displacement.
2. Final-LayerNorm chord bound at the actual displacement versus actual
   normalized-state displacement.
3. Centered-head operator norm times actual normalized displacement versus
   actual centered-logit displacement. Also measure its projection onto the
   centered head's row space; rank alone is not alignment evidence.
4. The universal quadratic KL bound using the actual centered-logit norm
   versus exact conditional KL (softmax curvature slack).
5. End-to-end theta JVP versus endpoint centered-logit displacement: norms,
   cosine, absolute Taylor remainder, and remainder relative to the larger of
   endpoint norm, JVP norm, and 1e-10. Also retain the analogous hidden-state
   JVP/remainder. Do not treat a near-zero endpoint ratio as stable evidence.

Report maxima, medians and exact P-weighted level means across all histories.
Histories are dependent nodes of one finite tree, not independent samples.
The heuristic first-order screen is worst-history scaled logit remainder <=25%;
it is a diagnostic screen, not a statistical or certification gate. Neither
passing nor failing one case settles the project-wide mechanism.

## Failure and interpretation

Any endpoint mismatch >1e-9, JVP/finite-difference discrepancy >1e-7,
missing history, nonfinite value, probability-mass mismatch, recorded-checkpoint
mismatch, or replay disagreement with the selected Round 9 condition invalidates
the diagnostic implementation. Preserve failures in their own output directory.

All actual Q states and endpoint changes are oracle diagnostics. They cannot
be reused as inputs to a P-only certificate. A good JVP supports a first-order
description on this interpolation only; it does not uniquely attribute small
output error to an output nullspace or certify a nonlinear remainder. A small
sampled remainder does not bound its supremum on theta in [0,1].

## Reproduction

From the standalone repository root, with a fresh output directory and the
original checkpoint stored under `histogram_d64_l2_seed11/checkpoint.pt`:

```text
python -B -m unittest discover -s experiments -p test_round9_directional_diagnostic.py -v
python -B experiments/round9_directional_diagnostic.py --config experiments/configs/round9_directional_diagnostic_v1.json --checkpoint-root PATH_TO_ORIGINAL_MODELS --run-dir runs/NEW_DIAGNOSTIC
```

The runner records sanitized source/input hashes and runtime versions. Model
files and operational retrieval/launch records remain private. Public scientific
outputs include config, prefix, checkpoint identity, per-history vectors,
slack summaries, checks and an interpretation with explicit oracle boundaries.
